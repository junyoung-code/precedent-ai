# 2C 임베딩 검색 구현 계획

> 기존 승인 설계의 `text-embedding-3-small`, 1536차원, 45/45/10 점수 정책을 작은 모듈로 구현한다.

## 체크리스트

- [x] 판결 결과·형량 문장을 제거하는 결정론적 임베딩 입력 생성기
- [x] OpenAI Embeddings API를 호출하는 교체 가능한 클라이언트
- [x] 벡터 모델·입력 해시·생성 시각을 저장하는 DB migration
- [x] 검증된 판례를 부분 재시작 가능하게 처리하는 백필 명령
- [x] semantic 45% + fact tags 45% + issue tags 10% 검색
- [x] 임베딩 비활성·호출 실패 시 2B 검색 fallback
- [x] 입력 불변성·응답 검증·검색 순위·DB schema 테스트
- [x] 전체 테스트와 production build 검증

## 구현 원칙

1. 사용자 요청마다 판례 원문을 외부로 전송하지 않는다. 저장 판례는 백필 명령에서만 임베딩한다.
2. 사용자 입력 임베딩은 `EMBEDDING_SEARCH_ENABLED=true`일 때만 호출한다.
3. 판결 결과, 유무죄, 형량 문장은 임베딩 입력에서 제외하며 검색 결과 객체에도 추가하지 않는다.
4. 외부 API가 실패하면 사용자 검색 자체는 실패시키지 않고 2B 검색으로 되돌아간다.
5. 키와 원문은 로그에 출력하지 않는다.
