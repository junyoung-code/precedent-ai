# 판례 AI

판례 AI는 사용자가 입력한 사실관계를 공개·검증된 판례와 비교해 유사한 판례, 같은 점과 다른 점, 근거가 연결된 AI 요약, 공식 원문 링크를 제공하는 프로토타입입니다. 현재 범위는 통신매체이용음란 판례입니다.

## 핵심 기능

- 국가법령정보센터에서 수집·검증한 판례만 검색 결과에 노출
- 의미 유사도 45% + 사실 태그 45% + 쟁점 태그 10% 혼합 검색
- 55점 미만은 판례를 생성하지 않고 빈 결과로 처리
- 동일 판례의 원문 문단에 근거한 `AI 생성 요약`
- 캡처 이미지는 브라우저에서만 미리 보고, 가려진 텍스트만 임시 세션에 저장
- 유무죄·고소 가능성·형량이 아닌 `사실관계 유사도`만 제공

## 실행

```bash
cd prototype
npm install
npm run db:up
npm run db:migrate
```

API와 화면은 각각 별도 터미널에서 실행합니다.

```bash
npm run api
npm run dev
```

## 검증

```bash
npm test
npm run build
npm run test:sites
npm run data:check
```

## 현재 상태

- 검증 판례 51건과 키워드·사실 태그·임베딩 혼합 검색 구현
- 실제 DB 검색 결과와 근거 기반 AI 요약 화면 연결
- 검색 품질 평가에서 Top-3 포함률 95%, 비관련 입력 빈 결과 정확도 100%
- 개인정보 가림과 최대 1시간 임시 입력 세션 구현
- 세션 수명주기, 실제 DB 무결성, 브라우저 E2E는 최종 통합 검증 중

상세 설계와 구현 계획은 [`docs/superpowers`](./docs/superpowers)에서 확인할 수 있습니다.
